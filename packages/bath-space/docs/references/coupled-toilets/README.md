- [Kohler Cimarron one-piece](https://resources.kohler.com/onlinecatalog/honedwhite/toilets/cimarron/one-piece.html): integrated body.

These are generic parametric studies, not branded replicas or manufacturer installation models. Reference screenshots are research artifacts and are not used as catalog thumbnails.

| Family | New models |
| --- | --- |
| Two-piece close coupled | Round front; comfort elongated; skirted; classic |
| One-piece | Compact; low profile; soft square; sculpted |

All eight models have independently adjustable bowl, base, seat, cistern and finish settings. Construction can switch between separate and integrated bodies. Tank taper, corner radius, lid thickness and two-piece joint gap are editable. Section A-A uses the same body profile as the mesh and includes the cistern lid and coupling or integrated rear body. Flush controls remain separate selectable items and follow the actual cistern lid height.

[Showroom scene graph](showcase.scene.json) contains all eight models and their controls. Run `bun packages/bath-space/scripts/create-coupled-toilet-showcase.ts` from the workspace root to generate the graph and save a fresh scene to the local editor at port 3002.
