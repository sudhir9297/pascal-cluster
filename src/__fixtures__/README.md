# Times Square road fixture

`osm-times-square-roads.json` is the imported road graph from an OpenStreetMap response captured on 2026-09-07, centered at latitude 40.758, longitude -73.9855, with a 250 m radius. It contains 61 road segments and 19 junctions, including short links and unequal road widths.

Source data © OpenStreetMap contributors, available under the Open Database License: https://www.openstreetmap.org/copyright. Source timestamp: 2026-09-07T04:42:51Z. The original response and import audit are in `docs/research/osm-road-audit/`.

The fixture tests run offline. It is a regression sample, not a claim that these mapped features have survey accuracy.

# Material comparison fixture

`road-material-comparison.json` is a synthetic three-road layout. Its styles are generated by the real OSM style normalizer using `surface=asphalt`, `surface=concrete`, and `surface=paving_stones`. It is designed for side-by-side rendering checks, not geographic comparison. Import it with the Streetscape panel's **Import JSON** command in a dedicated saved scene.

# Lane-arrow fixture

`road-turn-arrows.json` is a synthetic four-arm intersection built with the real OSM importer. One three-lane approach has `left|through|right`; the remaining approaches have no turn tags. It tests mapped arrows and missing-data behavior without claiming geographic accuracy. Import it through **Import JSON** in a dedicated saved scene.
