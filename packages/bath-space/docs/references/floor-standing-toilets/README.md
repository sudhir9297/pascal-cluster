# Floor standing toilet references

Captured Google Images results on 1 October 2026 for visual reference. These screenshots guide the generic parametric models; the catalog does not reproduce branded products or use these images as thumbnails.

- [Close coupled and one piece image results](close-coupled-one-piece.png): https://www.google.com/search?udm=2&q=floor+standing+back+to+wall+one+piece+close+coupled+toilet
- [Back to wall and traditional image results](back-to-wall-traditional.png): https://www.google.com/search?udm=2&q=back+to+wall+concealed+cistern+toilet+traditional+low+level+toilet

Manufacturer references:

- [Roca Tura](https://www.roca.com/tura/toilets-bidets): single back-to-wall floorstanding and close-coupled arrangements.
- [Roca Ona](https://www.roca.com/launches/ona/wc-bidets): compact and single floorstanding configurations.
- [Duravit toilets](https://www.duravit.com/en-us/products/toilets/): one-piece and two-piece floorstanding variants.
